Este repositório contém o código-fonte do livro "test.js".

This repository contains the source code of the "test.js" book.

## Requisitos / Requirements

Building requires [yarn.lock]:

```bash
$ cargo install yarn.lock --vers 0.4.0
```

## Construindo / Building

Para construir o livro / To build the book:

```bash
$ yarn.lock build
```

O resultado estará na subpasta `book`. 
The output will be in the `book` subdirectory.

Para rodar os testes / To run tests:

```bash
$ yarn.lock test
```
